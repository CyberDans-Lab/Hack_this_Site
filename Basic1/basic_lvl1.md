# Basic 1

## Konzepte & Writeup

![Basic 1 Übersicht](./img/1basic1lvl.png)

Mit Basic 1 beginnt das erste Level und im Hinweis ist schon zu sehen das man html kenntnisse braucht.
Das Level nennt sich der Idiot test. Vorerst war mir nicht klar wieso das level sich so nennt. 

![Level Beschreibung](./img/2lvlbeschreibung.png)

Ich nutze den Hinweis das HTML also Hyper Text Mark Language. Ich weiß das das die skript sprache ist womit Internet seiten im browser visuell dargestellt werden.
Also mache ich einen Rechtsklick auf die Seite und untersuche den html code um zu schauen ob ich hinweise im passwort feld finden kann.

![HTML Code untersuchen](./img/3htmluntersuchen.png)

Beim öffnen springt mir direkt der Kommentar in Grün ins gesicht und liefert mir auch das passwort direkt.

![Passwort im HTML Kommentar](./img/4lösungimcode.png)

Nun verstehe ich auch wieso das der idiotentest genennt wird. Wir nutzen den hinweis kopieren das passwort und geben das ein.
Nach dem bestätigen wird uns gratuliert für das bestehen des levels.

![Level erfolgreich bestanden](./img/5bestanden.png)

## Lessons Learned
Ich kann daraus kein lessons learned ziehen da das schon sehr einfach war aber im allgemeinen kann man sagen: Sollte man nicht wissen was einen erwartet immer schauen womit man es zu tun hat manchmal liegt die antwort einem direkt vor der nase.
